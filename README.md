# SkillBridge AI

Human Capital Digital Twin for Inclusive Workforce Networks.

## Problem

SkillBridge connects verified community workforce capacity
with short-term enterprise production demand.

## MVP

- Human Digital Twin
- Job Digital Twin
- Community Capacity Twin
- Explainable Matching
- Skill Verification Workflow
- Batch Quality Control
- Trust & Safety
- Social Impact Evidence

## Setup

python -m venv .venv
pip install -r requirements.txt
python scripts/generate_demo_data.py
streamlit run app.py

## Testing

pytest -q

## Security

Never commit real worker IDs, disability information,
identity documents, videos or API secrets.

## Data

Demo data is synthetic unless explicitly marked otherwise.
